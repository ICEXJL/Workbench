# SPEC-013 运营日报注意事项

状态：implemented；来源：用户确认后要求“开始实现”（2026-11-12）。

## 目标与边界
新增选填多行注意事项，覆盖表单提交、更新、清空、本人回显、历史只读和权限范围内日报列表。不修改销售统计、合规判断及组织范围，不新增对外同步服务。

## 角色与数据契约
operator/leader/manager 仅提交或更新本人当天日报，admin 不可提交。读取沿用 JWT 和组织可见范围；概览沿用 leader/manager/admin 可见。daily_report 新增 attention_notes TEXT NULL，无索引变化；API 使用同名 string|null。省略/空串/null 按空内容处理，已有文本可清除。文本以插值渲染，保留换行，禁止 HTML 执行。

## 展示与验收
1. 提交页面多行选填，保存后正常回显；历史日期只读。
2. 当前筛选记录有非空内容才显示注意事项概览卡，人数按 operator_id 去重；点击筛选至含内容的确切日报，避免跨日期误匹配。
3. 全量表格有内容显示该列，全部为空隐藏；单行空值为 -；抽屉无内容隐藏。
4. 旧行 NULL 兼容；销售快照后台刷新保留注意事项；无关日报字段不受影响。
5. 未登录 401、管理端提交 403；四角色越权指定 operator_id 时不执行数据查询。

## 迁移与同步
先执行 docs/sql/2026-11-12-report-attention-notes.sql，再更新后端/前端；新建库基线同步更新，启动兼容检查可补齐列。DDL 会隐式提交，应备份并低峰执行。回滚先退应用，保留可空列为首选；删列前导出注意事项数据。写入、读取及应用内销售快照更新链路已覆盖，仓库未包含外部日报同步任务，其验证不在本次已验证范围。
