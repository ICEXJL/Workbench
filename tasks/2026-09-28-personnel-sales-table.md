# 人员销售表优化

## 范围

- 每名运营汇总为一行，店铺编号、部门简称、组别和平台合并展示。
- 日期从最近到最早排列；运营按近 7 日销售额降序排列。
- 后端汇总每名运营名下店铺账号的 7 日销售额用于排序；页面不展示个人或跨运营合计列/总计行。

## 实现

- 后端 `/api/v1/sales/personnel` 按运营汇总账号销售，增加 `total_orders`、`total_sales`，并按 `total_sales` 降序排列。
- 前端日期顺序调整为最近到最早，隐藏个人合计列和跨运营总计行；每日销售额统一为 USD 格式。
- API 响应说明见 `docs/API_SALES.md`。
