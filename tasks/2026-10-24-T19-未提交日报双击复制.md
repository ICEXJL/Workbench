# T19 · 未提交日报卡片双击复制名单

日期：2026-10-24
状态：已完成并验证

---

## 1. 需求

日报进度页的「未提交日报」指标卡，**双击复制未提交人员名单**：

- boss（admin）筛选部门/组别后，复制的是该范围内全部未提交运营；
- 组长双击只能复制自己组内的未提交运营；
- 名单不受前端分页影响（是当前筛选范围的全量）。

---

## 2. 实现

### 2.1 抽出纯函数（`src/utils/reportFilters.js`）

| 函数 | 作用 |
| --- | --- |
| `pickUnsubmittedNames(rows)` | 从 `displayRows` 挑出 `submitted=false` 的人员姓名，过滤空值 |
| `buildNameListText(names)` | 拼成一行一个的文本 |

一行一个的原因：可直接粘进企业微信群催人，也能粘进 Excel 成一列。

### 2.2 卡片交互（`DailyReportList.vue`）

- `@dblclick` 绑定 `copyUnsubmitted`
- hover 时边框变色 + 外发光，`cursor: pointer`
- 文案从「需要跟进」改为「需要跟进 · 双击复制名单」（有人未提交时）
- `title` 属性带人数，鼠标悬停可见

### 2.3 剪贴板策略

优先 `navigator.clipboard.writeText()`；不可用时（非安全上下文，即 http 且非 localhost）
降级为隐藏 `textarea` + `document.execCommand('copy')`。

复制后 `message.success('已复制 N 位未提交人员')`；无人时 `message.info`。

### 2.4 数量与名单同源

```js
const unsubmittedNames = computed(() => pickUnsubmittedNames(displayRows.value))
const unsubmittedCount = computed(() => unsubmittedNames.value.length)
```

`unsubmittedCount` 改为由名单长度得出，避免「卡片显示 5 人但复制出 4 个名字」的不一致。

---

## 3. 权限为什么天然正确

名单来自 `displayRows` 中 `submitted=false` 的行，这些行由 `scopedPeople` 补出。而 `scopedPeople` 经过两层收窄：

1. **后端**：`/report/people` 走 `visible_people` → `visible_operator_ids`，只返回当前 JWT 权限范围内的人；
2. **前端**：再按部门/组别筛选（`filterReportPeople`）。

所以前端**不需要**额外判断权限，也不可能越权——组长拿到的 `people` 本来就只有组内的人。

## 5. 未做 / 注意

1. **未做浏览器端目视验收**：复制行为需要真实点击，本次验证的是名单计算范围与构建，剪贴板交互需登录后实测。
2. **没有复制标题行**。只复制姓名，方便直接粘贴；如需带「2026-10-13 未提交 5 人：」这类上下文，可以在 `buildNameListText` 上加参数。
3. **双击不够直观**。已在文案和 `title` 里提示，但如果用户反馈发现不了，建议改成单击或加一个复制图标按钮。
