# 经营总览店铺搜索与时间汇总

## 需求

- 店铺选择支持输入搜索，保留当前用户可见店铺范围。
- 经营总览默认显示昨天，使用昨天到昨天的日期范围。
- 增加周度、本月、上月快捷汇总，并保留自定义日期范围；范围结果按店铺聚合订单量与销售额。

## 实现

- `backend/routers/sales.py`：`/sales/daily` 增加 `start_date`、`end_date` 参数和日期范围校验，保留单日参数兼容。
- `backend/services/sales_service.py`：范围查询按店铺聚合，保留服务端权限范围、分页和排序；返回 `period_start`、`period_end`。
- `frontend/src/views/dashboard/DailySales.vue`：默认昨天到昨天；增加周度、本月、上月快捷按钮，保留自定义日期范围、可搜索店铺下拉、范围缓存键和范围明细列。
- `docs/API_SALES.md`、`AGENTS.md`、`specs/SPEC-012-经营数据工作台领域规格.md`：同步 API 和行为契约。
