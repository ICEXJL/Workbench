## 踩坑

- **Git Bash 下 `git status` 的中文路径被转义成八进制**，`grep "部署"` 匹配不到，
  看起来像没add 成功。用 `git status --short` 全量输出对照判断。
- `git add "中文路径.md"` 静默失败，不报错也不生效。要用完整 `git add -- "docs/部署与配置.md"` 并复核。
- `run_query` 不支持 LIKE 的 `%s` 参数绑定（报 1064语法错误），
  查模糊账号名要分两步：先 LIKE 查出真实值，再用精确 `IN ('a','b')` 拼进 SQL。
